# Komentář k zákonu č. 325/2021 Sb., o elektronizaci zdravotnictví

Otevřený komentář k zákonu o elektronizaci zdravotnictví — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; integrované datové rozhraní, identifikace zdravotnických pracovníků a pacientů, kmenové zdravotnické registry, služby vytvářející důvěru, centrální služby elektronického zdravotnictví, žurnál činností, výkon státní správy a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-2021-00325_2026-04-01`.
